# Security policy

## Поддерживаемая версия

До первого релиза исправления безопасности рассматриваются для текущей main.
Старые commits и сторонние версии Herdr не входят в поддерживаемую ветку.
Гарантированного срока ответа и отдельной службы поддержки нет.

## Сообщить об уязвимости

Используйте вкладку **Security → Report a vulnerability** в
[репозитории GitHub](https://github.com/Jaxak/herdr-app-groups-spaces).
Этот канал работает только после включения владельцем Private vulnerability reporting.
Его включение — обязательный пункт подготовки к открытию репозитория.

Если кнопки нет, не публикуйте подробности: создайте issue только с просьбой
включить приватный канал и дождитесь безопасного способа связи. Не отправляйте
секреты через обычный issue, PR, публичные логи или снимки.

В приватном отчёте укажите commit/версию мода, Herdr и ОС, шаги воспроизведения,
возможный ущерб и минимальный пример без действующих ключей и персональных данных.
Не публикуйте эксплуатационные детали до согласованного раскрытия.

## Модель доверия

Мод запускается с возможностями Herdr: это не sandbox для недоверенного кода.
Текущая реализация не использует exec, сеть или файловые API, но вызывает команды
Herdr; создание space запускает shell, а штатное меню может закрывать проекты
и выполнять worktree-действия.

Устанавливайте только просмотренный код в личную копию layout, сохраняйте резервные
копии состояния и не проверяйте разрушительные сценарии на рабочих терминалах.
Секрет, попавший в git, сначала отзовите: удаление файла не убирает его из истории.
