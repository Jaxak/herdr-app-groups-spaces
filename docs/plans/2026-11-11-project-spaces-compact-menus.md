# Project Spaces Compact Menus Implementation Plan

> **REQUIRED SUB-SKILL:** Use the executing-plans skill to implement this plan task-by-task.

**Goal:** убрать «…» у проектов, привести контекстные меню к штатному стилю Herdr и отделить нижнюю строку от рамки группы на 5 px.

**Architecture:** управление данными не меняется. Меню проекта открывается правым кликом; доступ с клавиатуры сохраняется через Shift+F10 на кнопке проекта. Кнопки «…» панели и групп остаются. Вместо центрированных Button-строк использовать штатную геометрию меню из `mods/menu` и `mods/agents`: ширина popup 200 px, внешние поля 5 px, строки 31 px без промежутков, шрифт 12,8 px, горизонтальные поля 8 px, скругление 7 px. Текст слева, отметка выбранной группы справа. Группам добавить нижнее поле 5 px без изменения лесенки.

**Tech Stack:** существующие GPUI builders и SVG Herdr, Node VM tests и `herdr-app check`. Без зависимостей и новых настроек.
