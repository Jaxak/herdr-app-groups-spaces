# Project Spaces Icons and Borders Implementation Plan

> **REQUIRED SUB-SKILL:** Use the executing-plans skill to implement this plan task-by-task.

**Goal:** добавить согласованные иконки и рамку группы, сохранив лесенку 5 px.

**Architecture:** группы получают штатный SVG `layers`, проекты — `folder`; общий label builder сохраняет одинаковую геометрию и обрезку названий. Рамка 1 px цвета `theme().border` со скруглением 6 px охватывает заголовок и содержимое каждой группы, включая пустые и «Без группы». В плоском режиме рамок нет, иконки проектов остаются. Состояние и действия не меняются.

**Tech Stack:** существующие `svg`, GPUI builders, штатные SVG Herdr, Node VM tests. Без новых зависимостей и загрузки файлов по сети.

---

### Task 1: Иконки и рамки

**Files:** `mods/project-spaces/main.js`, `tests/project-spaces.test.mjs`.

**TDD scenario:** Modifying tested code; исходные 39 тестов должны пройти, затем RED/GREEN для новых свойств.

1. Добавить `svg` в host shim с записью пути ассета. Проверить иконки проектов и групп; рамки именованных, пустых и нераспределённых групп; отсутствие рамок в плоском режиме и сохранение рамки при сворачивании.
2. Проверить сохранение шага 5 px между названиями с учётом ширины иконки и зазора; запустить тесты и подтвердить RED.
3. Использовать иконки 14 px с зазором 5 px и цветом `theme().muted`; сохранить слоты стрелок, названия слева, меню справа. Добавить рамку только контейнеру группы. Изменить отступ терминала на ширину иконки и зазора, чтобы не потерять лесенку названий.
4. Запустить Node-тесты, `herdr-app check mods/project-spaces`, `git diff --check`.
5. Без перезаписи пользовательских правок обновить установленный `main.js`, проверить installed mod, `status` и снимок окна. Не менять настройки, штатные моды и layout.
6. Коммит `(feat): добавил иконки проектов и рамки групп`.

Тёмная/светлая тема проверяются автоматическими описаниями с разными цветами. Реальный снимок — только в текущей теме; скрытые пользовательской настройкой терминалы не раскрывать автоматически.
