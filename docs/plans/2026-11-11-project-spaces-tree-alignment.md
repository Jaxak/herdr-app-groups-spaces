# Project Spaces Tree Alignment Implementation Plan

> **REQUIRED SUB-SKILL:** Use the executing-plans skill to implement this plan task-by-task.

**Goal:** заменить центрирование названий на дерево с согласованным шагом 5 px.

**Architecture:** изменить только описание строк в `main.js`. Названия групп, проектов и терминалов выровнять влево; место под стрелку одинаковой ширины сохранять и у проектов без терминалов. Проект сдвигается на 5 px относительно группы, название терминала — ещё на 5 px относительно проекта. В плоском режиме убрать только отступ уровня группы. Кнопки «…» остаются справа. Состояние и действия не меняются.

**Tech Stack:** существующие GPUI builders, Node VM tests, `herdr-app check` и снимок установленной копии. Без зависимостей и новой конфигурации.

---

### Task 1: Выравнивание и отступы

**TDD scenario:** Modifying tested code — базовый зелёный прогон, затем RED/GREEN для нового layout-контракта.

**Files:** `mods/project-spaces/main.js`, `tests/project-spaces.test.mjs`.

1. Проверить исходные 38 тестов.
2. Добавить проверки: названия слева; проекты имеют отступ 5 px только при группировке; подписи терминалов глубже на 5 px с учётом слота стрелки; слот сохраняется без терминалов; подпись вкладки не сжимается. Запустить и подтвердить RED.
3. Ввести одинаковую ширину стрелок группы/проекта 24 px. У отсутствующей стрелки оставить пустой слот той же ширины. Применить `justify_start()` к кнопкам названий, `ml(5)` к проекту в группе и `ml(24 + 4 + 5)` к терминалу; внутреннему ряду терминала дать доступную ширину, подписи вкладки — `flex_none()`.
4. Запустить все тесты, `herdr-app check mods/project-spaces` и `git diff --check`.
5. Проверить, что установленная копия не изменена пользователем, обновить только наш `main.js`, проверить installed mod и осмотреть `herdr-app shot`. Настройки пользователя и штатный layout не менять.
6. Создать коммит `(fix): выровнял дерево проектов с шагом пять пикселей`.

Ручная проверка сворачивания, фокуса и перезапуска остаётся отдельной частью общей приёмки. Если терминалы скрыты пользовательской настройкой, не менять её ради снимка без согласования.
