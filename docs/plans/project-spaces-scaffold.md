# Project Spaces — план минимального каркаса

**Goal:** создать первый коммит с модом, который показывает spaces и открывает настройки.

**Architecture:** один мод `mods/project-spaces/`, стандартный `View` и живые данные `spaces()`. Диалог настроек открывает тот же мод с `props.screen = "settings"`. Штатные моды и layout не изменяются.

**Tech Stack:** JavaScript, встроенные GPUI/herdr API; Node.js для тестов без зависимостей.

## Согласованные границы

- Проект = space. В дальнейшем — ручные именованные группы, максимум одна группа на проект.
- В дальнейшем мод заменит Spaces в копии layout; исходники остаются в этом репозитории.
- Сейчас: список spaces, выбор space, пустое состояние, открытие/закрытие настроек.
- Настройки пока объясняют, что переключатели появятся вместе с функциями. Группировка и вложенные терминалы не реализуются в первом коммите.
- Без установки в пользовательскую конфигурацию, сетевых запросов, запуска программ и новых зависимостей.
