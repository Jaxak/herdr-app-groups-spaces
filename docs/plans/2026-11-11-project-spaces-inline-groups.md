# Project Spaces: inline-группы и штатное меню Implementation Plan

> **REQUIRED SUB-SKILL:** Use the executing-plans skill to implement this plan task-by-task.

**Goal:** заменить модальное редактирование групп вводом в списке, убрать собственные контекстные меню и троеточия, вернуть меню space из Herdr.

**Architecture:** сохраняем `project-spaces.state`, модель имён и drag-and-drop. Черновик имени существует только на экземпляре панели, до Enter/✓ в shared ничего не записывается; Escape/× отменяют ввод. Для проектов открываем shipped `menu` с `{tab:"space", target:{id}}`, включая полные ID удалённых машин; не копируем его Git/worktree-код.

**Tech Stack:** JavaScript, GPUI/Herdr, Node.js test runner; без новых зависимостей.

---

## Согласованный UX

- Tooltip и accessibility label кнопки folder-plus: «Создать группу».
- В заголовке Spaces нет троеточия. У именованных групп — +, карандаш (square-pen), корзина (собственный trash.svg, поскольку у Herdr нет этой иконки), у корзины красная иконка при наведении. У «Без группы» нет редактирования и удаления.
- Создание показывает компактную строку с Input и кнопками ✓/× в списке; переименование — такую строку вместо заголовка группы. Поле занимает оставшуюся ширину, без модального окна и растягивания по высоте.
- Enter/✓ сохраняют после trim; пустое или повторное имя показывает ошибку под полем. Escape/× отменяют. При переименовании остаются ID, проекты, порядок и сворачивание. При устаревшем ID объект не создаётся заново.
- Удаление группы освобождает её проекты, но не закрывает spaces/терминалы. Повторное нажатие устаревшей кнопки ничего не меняет.
- Контекстные меню панели/групп и собственное меню назначений полностью удаляются. Назначение группы остаётся через drag-and-drop. Правый клик по проекту и Shift+F10 открывают штатный menu Herdr; worktree-пункты обеспечивает сам Herdr.
- В плоском режиме создание группы остаётся доступным; для работы с заголовками групп нужно включить группировку. Настройки и сохранённые группы не теряются.
- Обновляем уже подключённый мод в текущем layout после проверок, с резервной копией установленных файлов; layout и пользовательское shared-состояние не переписываем.
