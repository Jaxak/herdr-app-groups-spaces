# HEX-поле рядом с палитрой

## Поведение

- Для каждой группы и проекта рядом с шестью цветами и сбросом — поле `#RRGGBB`.
- Клик или клавиатурная активация поля включает inline-ввод; retained InputState
  создаётся в обработчике, не в render. Одновременно редактируется одна строка.
- Enter сохраняет полный шестизначный HEX, убирая внешние пробелы и нормализуя регистр.
  Неверный формат показывает ошибку под строкой, не меняя текущий цвет.
- Выбор палитры/сброс обновляет активное поле. Несохранённый ввод не теряется от
  посторонних перерисовок; переход к другой строке отменяет прежний черновик.
- HEX фиксированный, ANSI-цвета по-прежнему адаптируются к теме.

## Изменения и проверки

1. Регрессии в `tests/project-spaces.test.mjs`: RED для HEX в модели и обоих режимах,
   inline-ввода, ошибок, синхронизации палитры/сброса, старых callback и закрытой цели.
2. `model.js`: строгая проверка HEX, сохранение поддержки шести ANSI-токенов.
3. `main.js`: единое разрешение цвета, inline-редактор и ошибка в строке настроек.
   Обработчики перечитывают shared state и используют cx текущего callback.
4. Обновить USAGE, CHANGELOG и исследовательскую заметку. Выполнить `npm run check`,
   `npm run check:herdr`, native probes с активным Input/ошибкой и `git diff --check`.

Установленная копия не обновляется без отдельного разрешения. Layout, процессы,
shared.json, штатные моды, main и Git remote не меняются.
