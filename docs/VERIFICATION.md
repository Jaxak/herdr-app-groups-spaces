# Проверки перед слиянием Project Spaces

Дата: 2026-11-12. Это отчёт о проверенном объёме, а не объявление релиза
или полной готовности на всех платформах.

## Окружение

- Linux, Node.js 22.23.2.
- Herdr App 0.1.15.
- Основа ветки: main `5306400`; origin/main совпала с ней при fetch.

## Выполнено

- `npm run check`: синтаксис корректен, 95 тестов, 0 ошибок.
- `npm run check:herdr`: исходники загружаются нативным движком.
- Семь изолированных native probes без предупреждений: полный/компактный вид,
  настройки, активный HEX Input, ошибка ввода, смена редактируемой строки,
  длинный список настроек. Использовались тестовые данные; команды и записи
  в реальное состояние приложения были заблокированы.
- `git diff --check`; проверка локальных ссылок, JSON/YAML и состава файлов.
- Проверены root LICENSE/NOTICE и сохранность полных сторонних MIT/Apache лицензий.
- Ограниченный поиск типовых токенов/закрытых ключей в 46 уникальных blobs
  текущей ветки и индекса: совпадений нет; резервные ветки в этот проход не входили.
- Установленная копия совпадает с распространяемыми файлами; после hot reload
  `herdr-app status` не сообщает ошибок. Пользователь подтвердил визуальное
  поведение установленного мода и одобрил подготовку к слиянию.

Покрытие Node-тестов включает старое/неверное состояние, полные remote IDs,
исчезнувшие цели, две копии настроек, переносы, сохранение настроек/цветов,
восстановление раскрытия, tooltip и валидацию HEX. Это проверки модели
и описания интерфейса, а не нативная раскладка или полный UI end-to-end.

## Что не заявляется проверенным

- Реальный GitHub CI и локальный Node.js 24; матрица CI только настроена.
- macOS и Windows, другие версии Herdr.
- Перезапуск Herdr и восстановление с диска после него.
- Полная ручная матрица native focus/zoomed tab, удалённых машин и всех
  сочетаний drag-and-drop из [USAGE](USAGE.md#ручная-приёмка).
- Полноценный внешний secret scan всей истории. Ограниченный поиск типовых
  ключей/токенов не заменяет проверку перед публичным открытием репозитория.

Пользовательское одобрение интерфейса не заменяет эти проверки. Приложение
не перезапускали, рабочие терминалы не закрывали и указатель/клавиатуру
на рабочем дисплее не автоматизировали.

## Известные ограничения

Создание проекта не возвращает ID: наблюдение за единственным новым активным
space может ошибиться при параллельном внешнем создании. Автопрокрутки при drag
и синхронизации настроек между машинами нет. HEX фиксирован и требует выбора
контрастного цвета при смене темы. Подробности — в [USAGE](USAGE.md).

Push, слияние, теги, release и изменение настроек GitHub в эту подготовку не входят.
Резервные ветки `backup/*` сохраняются локально. Версия остаётся Unreleased.
