# Цвета и буквенные иконки проектов в Herdr

Проверено по установленному Herdr 0.1.15. Ниже — детали штатной реализации,
а не обещание стабильности её внутренних shared keys.
Пути источников приведены относительно Herdr home (`HERDR_APP_HOME`,
по умолчанию `~/.config/herdr-app`); штатные файлы не изменялись.

## Окрашивание

`svg(path)` наследует цвет текста; явный `.text_color(theme().ansi4)` или
`.text_color("#e3814f")` задаёт цвет маски. `image(path)` сохраняет исходные
цвета изображения. У штатной folder.svg обводка использует `currentColor`.

Источники: `gpui-kit.d.ts:20275–20292`, `gpui-kit.d.ts:1431`,
`mods/workspace-chrome/folder.svg`. Для иконок программ хост явно различает
`tint: true` → `svg`, иначе `image`: `herdr.d.ts:141–156`.

## Штатный Spaces

- В обычной развёрнутой строке это не SVG: квадрат 18×18 px, радиус 5 px,
  цветной фон, белый жирный текст размером 10.5.
- Надпись — `[...name][0]?.toUpperCase() ?? "?"`: первый Unicode code point
  имени в верхнем регистре, а не инициалы слов. Например, `backend-api` → `B`,
  `Мой проект` → `М`. Пустая строка даёт `?`.
- Вложенная worktree-строка вместо буквенного квадрата использует branch.svg.
- В компактном режиме штатный Spaces показывает номер `i + 1` и индикатор
  статуса, а не буквенный квадрат.

Источники: `mods/spaces/main.js:387–439`, `mods/spaces/main.js:444–457`.

## Цвета проектов

Карта хранится в `shared("space.colors")`, ключ — полный space ID, значение —
имя цвета (`ansi6` и т. п.) либо HEX. Для имён цветов Spaces использует свою
фиксированную палитру MARK, а не обязательно буквальное значение темы:
`#22a99a`, `#e3814f`, `#5b8def`, `#8b7cf6`, `#3fae6a`, `#d9649a`.

Новый обычный проект получает наименее используемый из шести цветов.
У существующих IDs назначения сохраняются при добавлении/переименовании;
IDs, отсутствующие в `spaces()`, штатная реализация удаляет из карты.
Для `~` автоматическое назначение пропускается.

Источники: `mods/spaces/main.js:39`, `mods/spaces/main.js:390–392`,
`mods/spaces/main.js:460–474`; тот же контракт описан в `mods/picker/main.js:11–35`.
В `SpaceInfo` готовой картинки/цвета аватарки нет: `herdr.d.ts:113–135`.

До добавления настроек цветов Project Spaces использовал `theme().muted` для
папки проекта и значка группы. Теперь индивидуальные цвета хранятся в собственном
`project-spaces.state` как ANSI-токены текущей темы либо фиксированный HEX `#RRGGBB`; `space.colors` по-прежнему
не читается и не меняется.

Если понадобится интеграция со штатной картой цветов, нужно учесть отсутствующие
назначения: основной Spaces может вообще не рендериться в layout с нашим модом.
Чтение карты не требует её очистки или перезаписи.

## Проверка

Изолированный `herdr-app check` принял SVG с цветом темы, SVG с HEX-цветом
и буквенный квадрат. Node asserts подтвердили выражение буквы для латиницы,
кириллицы и пустого имени. Временный probe удалён; установленный мод и состояние
не изменялись. Это проверка API/описания элементов, не снимок новых цветов
в живом интерфейсе.
