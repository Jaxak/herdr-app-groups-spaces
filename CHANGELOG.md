# Changelog

Здесь перечисляются изменения для пользователей. Даты, номера версий и ссылки
на теги добавляются только при фактическом выпуске; опубликованных релизов пока нет.

## [Unreleased]

### Добавлено

- Панель Project Spaces: существующие spaces как проекты, ручные именованные группы.
- Inline-создание и переименование групп, удаление без закрытия проектов и терминалов.
- Создание проекта штатной командой Herdr с последующим назначением группе.
- Перетаскивание проектов между группами и в корень; изменение порядка групп и spaces.
- Терминалы всех вкладок с иконками программ, выбором проекта/вкладки/pane по полным ID.
- Сохраняемые настройки группировки, видимости терминалов и сворачивания.
- Штатное меню проекта по правому клику и Shift+F10.
- Apache-2.0, сохранённые сторонние лицензии, правила разработки и безопасности.
- Команды проверок без зависимостей и GitHub Actions для Node.js 22/24.

### Ограничения до первого релиза

- Ручная нативная приёмка не завершена для всех сценариев и платформ.
- Создание проекта не возвращает ID: при параллельном внешнем создании возможно
  ошибочное автоматическое назначение единственного нового активного space.
- Автопрокрутки при перетаскивании и синхронизации настроек между машинами нет.

Актуальное поведение и подробные ограничения: [docs/USAGE.md](docs/USAGE.md).
