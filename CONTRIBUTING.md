# Участие в разработке

main — чистая основа репозитория. Реализация мода и инструкции установки
добавляются отдельным pull request из feature-ветки.

## Проверки

Нужны Node.js 22+ и npm. Установки зависимостей не требуется.

```sh
npm run check
git diff --check
```

Проверяются синтаксис и тесты инфраструктуры: метаданные, обязательные документы
и ограничения GitHub workflow. CI настроен для Node.js 22/24.
Herdr не устанавливается и не запускается; проверок ещё отсутствующего мода нет.

При добавлении фичи включите её код, тесты и команды проверок в тот же PR.
Для изменения логики сначала воспроизведите требование или ошибку тестом,
подтвердите ожидаемое падение, затем исправьте и прогоните весь набор.
Для интеграции с внешним приложением отдельно опишите нативную/ручную приёмку
и не представляйте тестовую замену API как проверку настоящего приложения.

## Pull request

- Ветка создаётся от main; один PR решает одну задачу.
- Опишите причину, поведение, риски и результаты проверок, включая пропуски.
- Обновите документацию и раздел Unreleased в CHANGELOG.
- Не добавляйте секреты, приватные артефакты или новые зависимости без обоснования.
- Сторонний код сопровождайте источником, версией/commit и полными лицензиями.
- Присылайте только материалы, которые вправе распространять.

Сообщения коммитов: `(тип): действие`, с русским глаголом в прошедшем времени.
Оригинальные вклады принимаются под Apache-2.0; сторонние части сохраняют свои условия.
Открытый PR не разрешает установку кода или изменение пользовательских процессов.

## Перед публикацией

Это checklist владельца; перечисленное не включается автоматически файлами репозитория.

- [ ] Просмотрены состав публикации, лицензии и история на секреты/приватные данные.
      Найденные секреты сначала отозваны; .gitignore не очищает историю.
- [ ] После отдельно разрешённого push прошёл настоящий GitHub CI.
- [ ] main выбрана default branch; настроена защита от force-push и удаления,
      обязательные CI checks и PR. Требования review учитывают число maintainer'ов.
- [ ] При открытии репозитория включён Private vulnerability reporting и проверен
      маршрут из SECURITY.md. До включения канала детали уязвимостей не публикуются.
- [ ] Проверены pinned actions, Dependabot alerts и доступные secret scanning /
      push protection. Автослияние и автопубликация не включались.
- [ ] Дополнительные проверки реализованных фич выполнены и описаны.
- [ ] В публичную отправку не включены локальные резервные ветки backup/*.

Рабочий email авторов разрешён владельцем. CODEOWNERS не заменяет branch protection.
Первый релиз, его версия, tag и смена видимости требуют отдельного решения;
до этого CHANGELOG остаётся Unreleased, package.json — private с версией 0.0.0.
Не объявляйте пользовательские возможности выпущенными до их включения в main.

Сообщения об уязвимостях направляйте по [SECURITY.md](SECURITY.md).
