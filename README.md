# Herdr App Groups & Spaces

[![CI](https://github.com/Jaxak/herdr-app-groups-spaces/actions/workflows/ci.yml/badge.svg)](https://github.com/Jaxak/herdr-app-groups-spaces/actions/workflows/ci.yml)

Репозиторий для разработки независимого мода Herdr.

**Ветка main содержит только базовую подготовку репозитория.**
Реализация групп проектов, пользовательского интерфейса и интеграции с Herdr
разрабатывается отдельно и добавляется через feature-ветку и pull request.
Инструкций установки мода и опубликованных релизов в этом каркасе пока нет.

## Что подготовлено

- [LICENSE](LICENSE) и [NOTICE](NOTICE): Apache-2.0 для оригинальных файлов.
- [AGENTS.md](AGENTS.md): правила для coding agents.
- [CONTRIBUTING.md](CONTRIBUTING.md): процесс разработки и checklist публикации.
- [SECURITY.md](SECURITY.md): порядок приватного сообщения об уязвимостях.
- [CHANGELOG.md](CHANGELOG.md): изменения инфраструктуры, пока Unreleased.
- EditorConfig, Git attributes и исключения локальных/секретных файлов.
- GitHub Actions с минимальными правами, pinned actions и Dependabot.
- CODEOWNERS и шаблоны issue/PR.
- Тесты метаданных, документов и ограничений CI.

## Локальные проверки

Нужны Node.js 22+ и npm. Зависимостей и сборки нет; npm install не требуется.

```sh
npm run check
git diff --check
```

Команда проверяет синтаксис и запускает тесты каркаса. CI настроен для Node.js
22 и 24. Команд установки или запуска Herdr в main нет.
Пакет помечен `private: true`, npm-публикация заблокирована;
версия `0.0.0` техническая и не обозначает опубликованный релиз.

## Разработка и публикация

Создавайте тематические ветки от main. Код фичи, её тесты, зависимости,
инструкции установки и пользовательские записи CHANGELOG добавляются вместе
в отдельном PR, а не объявляются уже готовыми в базовом каркасе.

Workflow и CODEOWNERS не включают защиту ветки автоматически. Настройка GitHub,
видимость, push, теги и релизы остаются отдельными решениями владельца.
Временные ветки `backup/*` — локальные резервные ссылки, не часть публикации.

Проект не является официальным выпуском Herdr. Оригинальные файлы каркаса
распространяются под Apache-2.0; сторонние лицензии добавляются вместе с кодом,
к которому они относятся.
